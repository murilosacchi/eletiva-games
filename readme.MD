# 🎮 Projeto Eletiva (Godot)

## 📦 Requisito

* Godot **4.4.1**
  (`Godot_v4.4.1-stable_win64.exe`)

---

## 📂 Como abrir

1. Abra o Godot
2. Clique em **Import**
3. Selecione a pasta:

   ```
   projeto-eletiva
   ```
4. Abra o arquivo:

   ```
   project.godot
   ```

---

## ▶️ Como rodar

As cenas estão na pasta:

```
/scene
```

Para rodar:

1. Abra uma cena `.tscn`
2. Pressione **F6** (Play Scene)

> ⚠️ Não use F5 (o projeto completo ainda não está configurado)

---

## ⚠️ Importante

* As fases **não estão interligadas**
* Cada cena funciona **separadamente**
* Ainda **não é um executável**
